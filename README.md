# NEXUS

**The AI-Native Engineering Workspace.**

Nexus is a next-generation engineering environment designed for a world where AI is the primary operator of code. It replaces the traditional, file-heavy IDE with a mobile-first "steering" interface centered on **Intent Orchestration**.

---

## 🚀 Vision: Brain & Muscle

Nexus operates on a bi-modal architecture:
- **The Brain:** High-level architectural reasoning and intent distillation via Gemini.
- **The Muscle:** Autonomous execution, real-time telemetry, and git synchronization.

---

## ✨ Features (Verified Prototype)

- **Mobile-First Card Deck:** Triage your projects and engineering intents through the high-fidelity "PCard" interface.
- **Project Blueprints:** Intelligent multi-file scaffolding for React PWAs, FastAPI backends, Chrome Extensions, and Data Science hubs.
- **Skill Marketplace:** Discover, install, and contribute neural modules through the "Registry Submission" portal.
- **CCC (Common Code Context):** A semantic graph explorer that visualizes your codebase as a network of symbols, not just folders.
- **Orchestration Chat:** Instruct the Nexus Brain to architect features, refactor logic, or audit security through natural language.
- **Live Build Artifacts:** Inspect distilled source code in a real-time, tabbed engineering dashboard.
- **Automated Testing:** Dedicated Vitest suite for verifying Store logic and AI orchestration.
- **NSP Telemetry (Simulated):** Visualizing the "health" and "latency" of your engineering nodes.

---

## 🛠️ Architecture Summary

- **Frontend:** React 19 + Vite + TypeScript
- **Styling:** Tailwind CSS + Framer Motion
- **State Management:** Zustand (Store-centric architecture)
- **Visuals:** React Flow (Graph Visuals) + Lucide (Icons)
- **Intelligence:** Google Gemini API (Client-side implementation)

## ⚡ Quick Start

```bash

```

### Development

```bash
npm run dev
```

### Build
Generates a production-ready static bundle in `/dist`.
```bash
npm run build
```

## 📋 Status & Audit Triage (v2.5p)

**Current Status: High-Fidelity Prototype**

The current repository is a visual and architectural demonstration. Most backend systems (Muscle Node, Git Sync, Persistence) are currently **simulated** via the Nexus Simulation Protocol (NSP).

**Top Priority Tasks:**
1. **Security:** Move Gemini API keys to a secure server-side proxy.
2. **Persistence:** Connect the Store to a database (Firestore/CloudSQL).
3. **Muscle Implementation:** Bridge the virtual "Artifacts" to a real filesystem.
